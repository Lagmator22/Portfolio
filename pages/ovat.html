OVAT

One YAML file and one command give you a tool-calling AI agent on an Intel AI PC.

OVAT, the OpenVINO Agentic Toolkit, replaces the client, schema and loop code that every agent project rewrites. You describe the model, the tools and the agent in workflow.yml. OVAT validates the file, wires everything to OpenVINO Model Server and runs the agent on CPU, GPU or NPU. No API keys, and nothing leaves the machine.

  • Four engines, one configA native loop, LangChain ReAct, LlamaIndex and the OpenAI Agents SDK sit behind one interface, so the same file runs on any of them.
  • Speaks the agent protocolsAn MCP client and server, an Agent2Agent server, and a terminal agent with subagents and permission prompts.
  • Routes across devicesServes 0.8B to 8B models over OpenVINO Model Server. Tool-calling agents also run on the NPU.
  • Diagnosis built indoctor, trace, telemetry and bench commands. I used them to trace unbounded memory growth (KV cache from 0.62 to 3.6 GB in about nine minutes) to a missing reply cap.
  • Tested like a productAbout 1,500 tests that run without a model server, and a rule that every fix ships with a test that fails without it.

Background

OVAT was my Google Summer of Code 2026 project with Intel OpenVINO: a large project over twelve weeks, from May to September 2026.

It grew out of OvaSearch, a C++ retrieval engine I had built on OpenVINO earlier that year, which became the prior art for the proposal.
